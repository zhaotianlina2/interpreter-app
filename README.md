# SimulCast｜同传工作台

SimulCast 是一个轻量的浏览器同传工作台：将英语或中文语音识别为文本并翻译成另一种语言，也可直接输入文本完成翻译。

## 功能

- **实时语音识别与翻译**：支持英语→中文、中文→英语；逐句显示识别结果、译文和翻译状态，并提供会话计时、延迟和句数等信息。
- **文字输入**：无法使用麦克风时，可通过手动输入走相同的翻译链路。
- **全文与术语**：在实时记录、双语全文和术语库三个视图间切换；添加固定译法，查看术语命中提示。
- **标记与导出**：为会话添加时间标记；复制全文或下载 TXT、SRT 字幕，也可清空当前会话。
- **可配置翻译服务**：可配置 DeepSeek、智谱 GLM、OpenAI 或自定义 OpenAI 兼容接口；未配置 LLM Key 时，页面会尝试其内置的 MyMemory 与 Google 翻译服务。

## 界面与交互

单页工作台以实时记录为中心，提供实时、全文、术语库标签，以及开始/暂停收音、文字输入、标记和导出等快捷控制。深色高对比界面使用蓝色强调色标示当前操作和实时条目，术语命中以琥珀色突出；窄屏下控制区会调整布局。

## 技术实现

项目目前由一个独立的 `index.html` 构成，HTML、CSS 与 JavaScript 内联实现，没有仓库内的包管理清单或构建脚本。语音识别使用浏览器 Web Speech API；设置和术语库存于浏览器 `localStorage`。翻译通过页面中配置的外部服务接口完成。

## 运行

这是静态单页应用，无需安装项目依赖或执行构建。可将 `index.html` 放在静态 Web 服务器上访问；如需使用麦克风，请通过 `localhost` 或 HTTPS 打开，并在浏览器中授予麦克风权限。源码提示 Edge/Chrome 支持其语音识别接口；实际可用性仍受浏览器版本、权限和网络环境影响。若不支持语音识别，仍可使用文字输入模式。

要启用可选 LLM 翻译，在设置中选择服务商或自定义兼容接口，填写接口地址、模型和 API Key 并保存。API Key、设置和术语库存于当前浏览器本地；识别出的文本会发送至所选翻译服务。使用前请确认服务商的网络可达性及数据处理政策。
